# Java 25+ — version-specific checks

Layer these on top of the base `ds-java-review` checklist when the project targets Java 25 or newer. Same checklist-as-a-lens discipline and output format as the base.

### Concurrency
- [ ] `ScopedValue` (final in 25, JEP 506) over `ThreadLocal` for immutable per-request context — no `--enable-preview`; note `orElse` no longer accepts `null`
- [ ] `StructuredTaskScope` for concurrent fan-out with a bounded lifetime instead of hand-managed `Future`s — still **preview** in 25 (JEP 525), so it needs `--enable-preview`; use the `open(...)`/`Joiner` form, not the older constructor API

### Language
- [ ] Flexible constructor bodies (final in 25, JEP 513) to validate arguments or initialize fields **before** `super(...)`/`this(...)` — instead of static-helper workarounds or an overridable method observing a half-built object
- [ ] `import module M;` (JEP 511) where a class draws broadly from one module and an explicit import list is just noise — not a blanket replacement for targeted imports
- [ ] Compact source files / instance `main` (JEP 512) only for scripts and small single-file programs (java.base is auto-imported there); production types stay explicitly declared
