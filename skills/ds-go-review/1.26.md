# Go 1.26+ — version-specific checks

Layer these on top of the base `ds-go-review` checklist when the project targets Go 1.26 or newer. Same checklist-as-a-lens discipline and same output format as the base.

### Idioms & patterns
- [ ] Pointer-to-value uses `new(expr)` — `new` now takes an expression, so `new(v)` replaces the hand-rolled `func ptr[T](v T) *T` helper for optional JSON/proto fields
- [ ] Self-bounded generics use a type parameter that references its own type-parameter list (e.g. `T Ordered[T]`) instead of an extra interface indirection, where it reads cleaner

### Tooling
- [ ] `go fix` is the canonical modernizer — rewritten on the analysis framework with ~two dozen modernizers; prefer it over `gopls`/`golangci-lint modernize` for surfacing safe upgrades to current idioms
- [ ] Heavy JSON paths have at least evaluated `encoding/json/v2` (`GOEXPERIMENT=jsonv2`) for its correctness and performance wins — but it is still experimental, so don't require it in production yet
