# Python 3.14+ — version-specific checks

Layer these on top of the base `ds-python-review` checklist when the project targets Python 3.14 or newer (`requires-python >= 3.14`). Same checklist-as-a-lens discipline and output format as the base.

### Typing
- [ ] Deferred annotations are the default (PEP 649/749) — forward references left unquoted and the now-redundant `from __future__ import annotations` dropped; annotations inspected via `annotationlib`, not `eval`

### Idioms
- [ ] `return`/`break`/`continue` inside `finally` treated as an error to fix — 3.14 raises a `SyntaxWarning` (PEP 765)
- [ ] Custom SQL/HTML/shell interpolation built on t-strings (`t"..."`, PEP 750) through a `Template`-aware API rather than f-strings — the literal itself sanitizes nothing; the processing function does

### Concurrency
- [ ] Free-threading is officially supported (PEP 779): on a free-threaded build, threads parallelize CPU-bound work — but shared state now needs real locking; the GIL is no longer there to mask races
- [ ] `InterpreterPoolExecutor` for subinterpreter parallelism where processes are too heavy and stock-build threads can't parallelize

### Security
- [ ] `tarfile.extractall` relies on the 3.14 default `filter='data'` (it now errors without a filter) — not reverted to the legacy unfiltered behavior

### Stdlib
- [ ] Zstandard via the stdlib `compression.zstd` instead of a third-party binding
